# Pemrograman Mobile (ST407)

Kumpulan seluruh tugas praktikum mata kuliah Pemrograman Mobile — S1 Informatika, Universitas Amikom Yogyakarta.

Setiap praktikum berada di branch-nya masing-masing:

| Branch | Pertemuan | Materi |
|---|---|---|
| [`p1-hello-world`](../../tree/p1-hello-world) | 1 | Pengenalan Flutter: hello world |
| [`p2-profil-mahasiswa`](../../tree/p2-profil-mahasiswa) | 2 | Widget modular: profil mahasiswa |
| [`p3-form-registrasi`](../../tree/p3-form-registrasi) | 3 | Stateful Widget & Form Handling |
| [`p4-state-management`](../../tree/p4-state-management) | 4 | State Management & Penyimpanan Lokal (InheritedWidget, SharedPreferences) |
| [`p5-secure-http`](../../tree/p5-secure-http) | 5 | Keamanan Data & HTTP Dasar |
| [`p6-rpl-keamanan`](../../tree/p6-rpl-keamanan) | 6 | Prinsip RPL & Keamanan Kode |

Branch p2–p4 berbagi riwayat awal yang sama karena pertemuan 2–4 dikerjakan berkesinambungan dalam satu proyek.
